Este repositorio acompaña a la Metodología de Investigación Algocrática, que forma una tríada con dos obras de Roiman Valbuena. Ciencia Pura (2025) aporta el fundamento lógico y ontológico. La Metodología Algocrática lo normaliza bajo estándares como IEEE 1012, IEEE 2841 e ISO/IEC 5259-2. Ciencia de Datos: Metodologías, Algoritmos y Aplicaciones con IA Moderna (2026) es su brazo ejecutor: el manual operativo donde cada fase del pipeline se programa y se valida con 26 ejemplos prácticos de medicina, finanzas e ingeniería, con código en Python y R. Si la metodología explica qué exigir y por qué, ese libro muestra cómo implementarlo; aquí, el código ejecutable es la tesis y el texto es su sombra documental.

Cita: Valbuena, R. (2026). Ciencia de Datos: Metodologías, Algoritmos y Aplicaciones con IA Moderna. Centro de capacitación Alternatica CENCAL.
